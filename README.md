🥁 Keyboard Drum Kit
A simple and interactive Drum Kit web application built with HTML, CSS, JavaScript, and Bootstrap. You can play different drum sounds by pressing the assigned keys on your keyboard.
✨ Features
🎹 Play sounds using keyboard keys

🥁 Multiple drum sounds

🔊 Audio playback using HTML5 Audio

⚡ JavaScript keyboard event handling

🎨 Styled with CSS and Bootstrap

💻 Simple and beginner-friendly project

🌐 Runs directly in the browser

🛠️ Technologies Used
HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript – Keyboard events and audio functionality



HTML5 Audio – Playing drum sounds

🚀 How to Run
Clone the repository:

git clone https://github.com/your-username/keyboard-drum-kit.git

Open the project folder.

Make sure all .mp3 files are in the correct location.

Open index.html in your browser.

Press A, S, D, F, G, J, K, or L to play the sounds.

🎮 Keyboard Controls
A → Clap
S → Hi-Hat
D → Kick
F → Open Hat
G → Boom
J → Snare
K → Tom
L → Think
